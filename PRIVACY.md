# Privacy policy — Web Debug Agent

Web Debug Agent collects no data and sends nothing to anyone but you.

- The extension runs only on pages served from `localhost`, `127.0.0.1` and `*.localhost`.
- What you select (element tree, CSS rules, an optional screenshot of the tab you pressed the shortcut in) is handed to a helper on **your own machine**, which writes it into the Claude Code session or Codex thread you picked. Nothing leaves your computer.
- No analytics, no accounts, no remote servers. The extension has no network access beyond your loopback interface.
- Screenshots are stored under `~/.webdbg/shots` on your machine and pruned automatically.
